# GLB Studio × TripoSR (local AI backend)

This is a **prototype**, not a hosted API. GitHub Pages cannot run the AI model.
It receives a cropped product image and returns a GLB mesh generated by [TripoSR](https://github.com/VAST-AI-Research/TripoSR). The model guesses unseen geometry; output quality varies. The GLB is a geometry-first reconstruction and **may not preserve product colors/textures**.

## Prerequisites

Python 3.10, git, sufficient RAM, and preferably an NVIDIA GPU. TripoSR has its own installation and GPU/CUDA requirements. CPU mode is slower and may run out of memory.

## Install

From the repository root:

```bash
git clone https://github.com/VAST-AI-Research/TripoSR.git ai-backend/TripoSR
python -m venv .venv
source .venv/bin/activate
pip install -r ai-backend/TripoSR/requirements.txt
pip install -r ai-backend/requirements.txt
```

On Windows PowerShell activate using `.venv\Scripts\Activate.ps1`. Follow TripoSR's upstream README if its dependencies require platform-specific installation.

## Start

From repository root:

```bash
export TRIPOSR_DIR="$PWD/ai-backend/TripoSR"
export TRIPOSR_DEVICE=cpu
python -m uvicorn ai-backend.app:app --host 127.0.0.1 --port 8001
```

Because the folder name `ai-backend` contains a hyphen, run the API from inside that directory instead:

```bash
cd ai-backend
export TRIPOSR_DIR="$PWD/TripoSR"
python -m uvicorn app:app --host 127.0.0.1 --port 8001
```

Set `TRIPOSR_DEVICE=cuda:0` if your TripoSR setup supports CUDA.

**Important:** An HTTPS GitHub Pages page generally cannot call a plain HTTP service on your own machine because of mixed-content/private-network restrictions. For a real integration, expose the backend over HTTPS via a trusted tunnel/reverse proxy and paste its `https://.../generate` URL into GLB Studio. Do not expose this unauthenticated prototype publicly: it has no authentication, quotas or concurrency limits.

Use `GET /health` to check installation. The browser sends multipart `image` to `POST /generate` and expects binary GLB. Default CORS allows `https://kore-benri.github.io`; adjust `ALLOWED_ORIGINS` if needed.

### Limitations
- One image is not sufficient to recover the true back of an object.
- TripoSR inference downloads model weights on first run.
- API request may take minutes and could time out on CPU.
- This integration has not been end-to-end tested in a GPU environment.
